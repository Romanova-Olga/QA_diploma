# YouGile QA Automation

Проект автоматизации  для системы управления проектами YouGile. 
Включает в себя UI-тесты (канбан,мессенджер, воронка продаж) и API-тесты.

## 🛠 Стек технологий
* **Python 3.11+**
* **Pytest** — фреймворк для написания и запуска тестов.
* **Playwright** — инструмент для UI-автоматизации.
* **Allure** — генерация отчетов о тестировании.
* **Requests** — библиотека для API-тестирования.

## 📂 Структура проекта
* `API_tests/` — тесты для проверки API (классы-клиенты, тесты, фикстуры).
* `UI_tests/tests/` — UI-тесты и Page Object Model (POM) классы для страниц.
* `.env` — файл с переменными окружения (URL, токены, логины/пароли).
* `requirements.txt` — общие зависимости проекта.
* `README.md` — документация проекта.
